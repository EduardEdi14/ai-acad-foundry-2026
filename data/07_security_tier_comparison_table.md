# Security Features by Account Package

The table below outlines the security features included with each account package:

| Package Type | Biometric Login | Real-Time Transaction Alerts | Device Binding | Fraud Reimbursement Cover |
| :--- | :--- | :--- | :--- | :--- |
| **Standard** | Included | SMS only | No | Up to 500 EUR |
| **Silver** | Included | SMS + Push | Up to 2 devices | Up to 2,500 EUR |
| **Platinum** | Included | SMS + Push + Email | Up to 5 devices | Up to 10,000 EUR |

Device binding restricts login to explicitly approved phones or computers; a login attempt from a new device requires an extra verification step regardless of package.
